# 0.9.4 分享版验证说明

## macOS

原工程已通过 243 项模型测试和 164 项展示/资源/集成检查，共 407 项。本次通用构建再次执行这些检查，并验证应用代码签名、Apple Silicon / Intel 双架构可执行文件及 ZIP 完整性。实际安装版已观察到正常的全局键盘、修饰键输入连接和增加的计数。

Mac 下载包未做 Apple Developer ID 签名、公证；使用本地 ad-hoc 签名。每次重新构建后输入监控可能需要重新授权。分享版没有更改用户当前安装的应用或本地进度。

## Windows

首次移植使用 .NET 10 / WPF / Win32 Raw Input。核心规则测试覆盖物理按下、自动重复排除、双键盘独立性、修饰键、滚动时间窗、午夜、睡眠、换装、提醒、休息与存档恢复，并检查全部帧和装扮图层。

Windows CI 使用真实的 Windows runner 构建自带运行时的 x64 包，启动原生透明窗口，检查 Raw Input 注册，注入应用回调以检查按下动作的即时落点，并输出 12 种状态、100 套装扮的 WPF 渲染图和 `report.json`。这些证据作为 Actions artifact 保存。

自动检查不等于实体电脑验收。Windows 的真实键盘/鼠标完整输入路径、混合 DPI 多屏拖动、输入法、系统休眠和长时间驻留仍需用户体验反馈。程序不声称 CI 注入就是实际硬件按键。

## 发布文件

每个 ZIP 附带 SHA256。下载包只含应用、运行必需素材、许可和使用说明；仓库只含源码、素材、文档和构建流程，不含本机用户存档、诊断快照或授权信息。

# 0.10.0 计时器版验证说明

新增下班、自由倒计时、番茄钟。Mac 共 442 项检查通过（原有 407 项、29 项计时规则、6 项原生计时 UI 集成）；Windows 核心/素材/计时规则共 265 项通过。发布前再次在 GitHub 的 Mac 和 Windows runner 上构建与检查。

计时规则覆盖暂停/继续、暂停存档恢复、重启和睡眠后的过期提醒、截止时间边界、重复计时、隐藏显示、并行事项、20 项容量、周末跳过、番茄长短休息、等待确认及不虚增输入计数。Mac 原生窗口验证计时区域的点击路由和暂停按钮，并检查扩展高度在小屏幕内仍保持比例。

Windows 启动检查新增真实 WPF 计时面板与倒计时区域的渲染、暂停/继续按钮事件、到点等待确认、非激活气泡和输入计数不变检查。两端计时窗口和到点气泡导出图片作为 Actions artifact 保存。程序化控件事件检查不等于真实硬件按键或人工体验验收。

首次移植的 Windows 版仍需实体电脑上的完整人工体验，尤其是输入法、混合 DPI 多屏、休眠和长时间驻留。Mac / Windows 分享包没有商业代码签名，Mac 尚未 Apple 公证。

旧的 0.9.4 安装与真实输入验证记录仍保留在本地制作工程，当前源码和构建证据以 0.10.0 为准。原计数、装扮、提醒的持久化字段保持；Mac 新增 `timers.v1`，Windows 在原 state.json 中新增 Timers；加载旧存档不会清空已有进度。
